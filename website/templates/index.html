Project Overview

Summary

The Degree Admin project is designed to help students easily track, manage, and plan their academic progress. It provides a clear overview of majors, minors, and course requirements, ensuring students stay on track for graduation while also meeting their long-term academic goals. The system allows both students and faculty to interact with the requirements for the student and System Administrators will have access to the course catalog for adding and removal of courses.

🎯 Goal

Create a user-friendly degree management system.

🛠 Tech Stack

  • Frontend: HTML, CSS
  • Backend: Python (Flask)
  • Database: MariaDB
  • Version Control: GitHub + GitHub Pages
